# Velja — Free Offline Installer

![Category](https://img.shields.io/badge/Browser_Picker-blue?style=flat-square)

## About

Velja is a free macOS browser picker that lets you open links in different browsers based on rules. Set a default browser, then configure rules to automatically open certain domains or URL patterns in specific browsers — work links in Chrome, personal links in Firefox, video calls in Safari. Velja eliminates the friction of manually switching browsers for different contexts.

## Common Problems & Limitations

- **macOS Only** — macOS-specific browser management tool
- **Rule Configuration** — Maximum value requires setting up URL rules per domain
- **Browser Detection** — Requires installed browsers to be detected by Velja
- **System Integration** — Must be set as the system default browser to intercept links
